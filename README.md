# 🧮 Calculadora de Horas de Trabalho vs. Consumo

Projeto em Python desenvolvido para calcular exatamente quantas horas (e dias) de trabalho são necessárias para adquirir um determinado produto ou serviço, com base no salário líquido do usuário.

## 🚀 Funcionalidades
- Cálculo do valor exato da hora de trabalho.
- Conversão do preço do item em horas e jornadas de trabalho necessárias.
- Interface simples via terminal.

## 🛠️ Tecnologias Utilizadas
- **Python 3**

## 🏁 Como Executar o Projeto
1. Certifique-se de ter o Python instalado em sua máquina.
2. Baixe ou clone este repositório.
3. Execute o arquivo principal pelo terminal:
   ```bash
   python main.py
